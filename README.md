# Davinci-Resolve-FFMPEG-Scripts

Scripts to help you with encoding on linux and edit with compatibility

# AV1 & MJPEG For Importing Videos (NOTE: Ignore If you are a Studio User)

You will have 2 .sh files whichever will do the job it just depends on what you prefer, all that's changed is one is av1 and other is mjpeg and both have audio to PCM (PCM is the only audio codec supported on linux if you want to different, there is flac i have put)

To Use just download the file and drag and drop onto the terminal and it will do the job but i will recommend creating a folder and putting your footage there and then opening a terminal in that directory!

# Convert Audio To Flac

There is no AAC or Opus support in Davinci Resolve Free & Studio so you need to convert audio, i have included a .txt file to help just copy and paste in the terminal and change the name (original.mp4) to the video you want to transcode's name

# Compress MP4 video

This is if your video is too big in storage and you want to compress it or you want to turn it into a mp4 you can send if you are a free user, First rename the video to .mp4 and then compress and then turn the audio into flac and it will send to social medias.


# More Easier Way

For the importing videos you can do this for too but i think the .sh is enough easy already, for the rest i recommend [Handbrake](https://flathub.org/apps/fr.handbrake.ghb) it is a more easier way to turn your video into a mp4 with h264 or h265 or AV1 and it will also convert audio to AAC so if you are a GUI guy i recommend it.
